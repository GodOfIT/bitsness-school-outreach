## 6. Khung chấm điểm (framework)

### 6.1. Công thức

```
Tổng điểm (0–100) = SUMPRODUCT(điểm C1..C11 × trọng số) / (5 × tổng trọng số) × 100
```

- Mỗi tiêu chí được chấm **1–5** (có thể dùng 2 và 4 cho mức trung gian).
- **Đợt:** nếu Vùng = "Ngoài HN" → **Đợt 4**. Ngược lại, điểm ≥ **70** → **Đợt 1**; ≥ **65** → **Đợt 2**; còn lại **Đợt 3**. Ngưỡng sửa được.
- **Gói chào mở cửa (tự động):**
  - C1 ≥ 4 → "LMS + số hóa học liệu"
  - C1 = 3 → "Nâng cấp/thay LMS + số hóa học liệu"
  - C1 ≤ 2 → "Số hóa học liệu, chạy trên LMS sẵn có"
  - cộng thêm " + mô phỏng" nếu C2 ≥ 4, " + ngoại ngữ" nếu C3 ≥ 4.

### 6.3. Cách chấm sơ bộ hiện tại (để kiểm tra/phản biện)

Code: `scripts/data.py`. Mỗi dòng trong `data/schools_scored.csv` có cột `can_cu_cham` ghi lý do từng tiêu chí.

- **C1** suy từ cột hiện trạng LMS của file gốc, theo từ khóa:
  - "tự phát triển" / "Smart Campus" → 1
  - "Đã có LMS / hoàn chỉnh / chuyên sâu / chuẩn / đồng bộ" → 2
  - "Moodle" hoặc e-learning lý thuyết → 3
  - "cơ bản" / Google Classroom / chỉ có phần mềm thi trắc nghiệm → 4
  - "Chưa có…" → 5
- **C2:** đếm số nhóm ngành khớp theo từ khóa (điện/điện tử/mạch/IoT/tự động hóa…; ô tô/cơ khí/CNC/xây dựng/thiết bị…; y/dược/điều dưỡng/xét nghiệm…; hóa/sinh/nông nghiệp/chế biến/xét nghiệm…). 0 nhóm → 1, 1 → 3, 2 → 4, ≥3 → 5. Cộng 1 nếu file gốc ghi "Rất khớp/Cực khớp".
